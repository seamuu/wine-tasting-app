# Offline map backgrounds

Country outlines and host-only orientation labels from Natural Earth Admin 0, 1:110m.

- Dataset: https://www.naturalearthdata.com/downloads/110m-cultural-vectors/110m-admin-0-countries/
- Source: https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_110m_admin_0_countries.geojson
- Terms: https://www.naturalearthdata.com/about/terms-of-use/ (public domain)
- GeoJSON SHA-256: 6866c877d39cba9c357620878839b336d569f8c662d3cfab4cb1dbe2d39c977f

Generated by scripts/build-maps.mjs. These SVGs have no script, network dependencies, wine markers, or answer keys. The shared GridMap component draws the versioned grid on top. Country boundaries are orientation aids; quiz points depend only on grid cells.

## France reveal illustration

`lib/france-map-geometry.json` contains the reusable outline and river paths for `FranceWineMap`. Rebuild it with `scripts/build-france-reveal-map.mjs`, passing [Natural Earth 1:50m countries](https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_50m_admin_0_countries.geojson) and [Natural Earth 1:10m rivers](https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_rivers_lake_centerlines.geojson). Both datasets are public domain. Overseas French polygons are excluded from this metropolitan-France illustration.

Wine-region patches in `lib/france-wine-map.ts` are schematic, with the same six regions used in the quiz clues. They are not legal appellation boundaries. The faint grid is a visual reference only: it has no quiz cell labels and does not replace the printed Jancis Robinson grid. No scoring or printed material is changed.

Village markers use commune centres from the [French government geographic API](https://geo.api.gouv.fr/decoupage-administratif/communes), checked 13 November 2026: Pargny-lès-Reims (51422), Lugny (71267), Rully (71378), Sologny (71525) and Bommes (33060). Producer/wine associations and location limits are recorded in `artifacts/imeto-julebord/wine-reveal-research.md`. These are village or producer-base markers, not exact vineyard coordinates. Jobard highlights Burgundy without an unverified village pin; Pascerette explicitly identifies its producer’s base, with the wine’s vineyard origin unconfirmed.
